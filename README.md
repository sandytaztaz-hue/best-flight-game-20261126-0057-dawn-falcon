DAWN FALCON — Fog Archipelago Ring Run is a photorealistic F-16-style jet campaign for desktop browsers: Dawn-1 flies six dawn legs across a foggy island archipelago, threading glowing rings through fog gaps, defending the lighthouse and fishing fleet, escorting a seaplane past raider jets, and duelling the hidden ace Ghost as the sun breaks through. Its signature RING COMBO mechanic builds a score multiplier up to ×2.5 as rings are flown in sequence, with radar pings revealing the next ring through the fog. The game has a real cockpit with lit gauges and a full HUD (altitude, speed, heading, radar, fuel, hull, lock bracket), seven hangar upgrades, three save slots, named crew with radio dialogue, WebAudio sound, and four staged screenshots rendered from the game's own code. Open `game/index.html` in a browser or serve the `game/` folder — no build step, no network requests.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && python3 -m http.server 8080 --directory out/game
```
